# Corral

An agent-first terminal multiplexer: a Rust daemon that owns panes, agent
sessions, and state, with TUI, CLI, and HTTP surfaces over it.

This repository is an empty scaffold by design: the design phase is done
and the first implementation plan is written, but no application code has
landed yet. v0.1 is the mux skeleton - panes, splits, PTYs, and the
daemon-plus-TUI core. It lands on the `v01-mux-skeleton` branch and merges
to `main` when the sprint gates pass.
